# Roadmap

## Fase 01 - Levantamento e definição

- ID: F01
- Objetivo: consolidar escopo, público e requisitos iniciais.
- Passo a passo:
  1. Revisar as informações do README e do site antigo.
  2. Definir público-alvo, objetivo do site e mensagem institucional.
  3. Confirmar os cursos técnicos que serão exibidos.
  4. Validar quais informações serão exibidas em cada curso.
  5. Registrar os requisitos mínimos para notícias e área administrativa.

## Fase 02 - Estrutura do projeto

- ID: F02
- Objetivo: preparar a base técnica e a arquitetura do projeto.
- Passo a passo:
  1. Inicializar a aplicação com TypeScript e React.
  2. Configurar a estrutura de pastas do projeto.
  3. Definir a organização de componentes, páginas e estilos.
  4. Preparar o ambiente de desenvolvimento local.
  5. Estabelecer a base para navegação e layout responsivo.

## Fase 03 - Conteúdo e dados

- ID: F03
- Objetivo: montar os dados base do site.
- Passo a passo:
  1. Listar todos os cursos técnicos disponíveis.
  2. Definir as matrizes curriculares de cada curso.
  3. Criar descrições curtas e objetivas para cada disciplina.
  4. Registrar os dados iniciais de notícias e destaques.
  5. Organizar os dados em formato estruturado para uso no frontend.

## Fase 04 - Interface institucional

- ID: F04
- Objetivo: criar a identidade visual e as páginas essenciais.
- Passo a passo:
  1. Desenvolver a página inicial com apresentação da escola.
  2. Criar a seção de cursos com cards e filtros simples.
  3. Incluir blocos de destaque institucional e diferenciais da escola.
  4. Definir paleta, tipografia, espaçamento e responsividade.
  5. Ajustar o layout para desktop, tablet e mobile.

## Fase 05 - Detalhamento dos cursos

- ID: F05
- Objetivo: apresentar informações pedagógicas dos cursos.
- Passo a passo:
  1. Criar páginas ou seções para cada curso técnico.
  2. Exibir descrição geral do curso.
  3. Mostrar matriz curricular com disciplinas e carga horária.
  4. Destacar objetivos, público-alvo e perfil do egresso.
  5. Garantir navegação clara entre os cursos e a página inicial.

## Fase 06 - Área administrativa

- ID: F06
- Objetivo: permitir o gerenciamento interno do conteúdo.
- Passo a passo:
  1. Implementar a tela de login para administradores.
  2. Criar painel básico para cadastro de notícias.
  3. Permitir edição de conteúdo por meio de formulário simples.
  4. Adicionar autenticação mínima com armazenamento local em SQLite.
  5. Validar fluxo de criação, visualização e publicação de notícias.

## Fase 07 - Integração e publicação

- ID: F07
- Objetivo: conectar dados e entregar as páginas em funcionamento.
- Passo a passo:
  1. Integrar os dados de cursos e notícias ao frontend.
  2. Visualizar a página inicial com conteúdo dinâmico.
  3. Validar que as notícias aparecem corretamente no site público.
  4. Testar navegação, links e carregamento de páginas.
  5. Ajustar textos, imagens e ordens de apresentação.

## Fase 08 - Qualidade e entrega

- ID: F08
- Objetivo: concluir o projeto com validação final.
- Passo a passo:
  1. Realizar testes em navegadores modernos.
  2. Verificar compatibilidade em dispositivos móveis.
  3. Corrigir erros de layout, navegação e conteúdo.
  4. Revisar acessibilidade e legibilidade geral.
  5. Preparar a entrega final com documentação mínima e ajustes finais.
