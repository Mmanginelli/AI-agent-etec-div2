# Stack Técnica

## Frontend

- TypeScript como linguagem principal
- React com Vite para estruturação da aplicação
- Componentização para páginas institucionais e módulos de conteúdo
- Layout responsivo para desktop, tablet e mobile
- Navegação moderna com foco em usabilidade e acessibilidade

## Backend e dados

- SQLite como banco de dados inicial
- Estrutura leve para persistência de notícias e dados administrativos
- Persistência de cursos e matrizes curriculares em dados estruturados

## Administração

- Sistema de login para área administrativa
- Painel para cadastro, edição e publicação de notícias
- Controle simples de autenticação para uso interno da escola

## Qualidade e entrega

- Compatibilidade com navegadores modernos
- Foco em performance e carregamento leve
- Código organizado para manutenção futura e expansão da plataforma
